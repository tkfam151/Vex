# VEX Robotics Tycoon (Roblox Studio)

A multiplayer tycoon where you run a robotics team workshop. You make parts, design VEX-style robots from modules, put them to work for income, enter tournaments, and drive them in a practice field and ranked 1v1 matches.

The **whole map is generated by code**, so you don't need to build or model anything. Install the scripts and press **Play**.

---

## Installing (pick one)

### Option A: One paste (fastest)
1. Open Roblox Studio and create a new **Baseplate** place.
2. Open the Command Bar with **View → Command Bar**.
3. Open `Installer.lua`, select everything, copy it, paste it into the Command Bar and press **Enter**.
4. The Output window should say *"VEX Robotics Tycoon installed!"*. Press **Play**.

### Option B: Copy-paste each script
Create these objects in the **Explorer** (right-click the parent → *Insert Object*). Name each one exactly as shown, then paste the matching file's contents into it.

| Create this | Type | Inside | Paste from |
|---|---|---|---|
| `Config` | ModuleScript | ReplicatedStorage | `src/ReplicatedStorage/Config.lua` |
| `DataManager` | ModuleScript | ServerScriptService | `src/ServerScriptService/DataManager.lua` |
| `RobotBuilder` | ModuleScript | ReplicatedStorage | `src/ReplicatedStorage/RobotBuilder.lua` |
| `WorldBuilder` | ModuleScript | ServerScriptService | `src/ServerScriptService/WorldBuilder.lua` |
| `TycoonServer` | Script | ServerScriptService | `src/ServerScriptService/TycoonServer.server.lua` |
| `ArenaServer` | Script | ServerScriptService | `src/ServerScriptService/ArenaServer.server.lua` |
| `MainUI` | LocalScript | StarterPlayer → StarterPlayerScripts | `src/StarterPlayerScripts/MainUI.client.lua` |
| `DriveClient` | LocalScript | StarterPlayer → StarterPlayerScripts | `src/StarterPlayerScripts/DriveClient.client.lua` |

### Option C: Rojo
`default.project.json` is included. Run `rojo serve` and connect from the Rojo plugin.

### Saving progress
Saving only works after you **publish** the place (File → Publish to Roblox). In Studio you also have to turn on **Game Settings → Security → Enable Studio Access to API Services**. Without that the game still runs, but progress isn't saved.

### Testing ranked 1v1
Ranked matches need two players. In Studio go to **Test → Clients and Servers**, set **2 Players**, and click **Start**.

## How to play

1. **Workshop (tycoon).** You're given one of 6 team workshops when you join. Step on the green buttons to buy machines. Machines drop parts onto the conveyor, the parts get worth more as they pass through upgraders, and the collector stores the cash. Step on the **collect pad** to cash out.
2. **Robot Lab** (🤖). Buy the *Robot Assembly Station* first. Each robot has 4 module slots:
   - **Drivetrain**: speed and pushing power. Mecanum and X-Drive can strafe.
   - **Intake**: how many balls the robot can hold.
   - **Lift**: points per ball.
   - **Brain**: control, plus free autonomous points at the start of a match.

   Unlock parts, equip them, then press **Build Robot**.
3. **Garage** (🏠). Built robots sit in Robot Bays and **earn cash every second**. ⭐ marks your *active* robot, which is the one used for competitions and driving.
4. **Competitions** (🏆). These are auto-simulated tournaments, from Club Scrimmage up to the World Championship. They run Quarterfinals → Semis → Finals, and your robot's rating decides the outcome. You win cash and trophies.
5. **Drive** (🎮). There are two ways to drive your robot:
   - **Practice field**: earn cash per point.
   - **Ranked 1v1 arena**: queue against another player for a 90-second match. You get auton bonus points at the start, and the winner gets trophies and cash.

   Controls:
   - **W/S**: drive. **A/D**: turn.
   - **Q/E**: strafe (holonomic drivetrains only).
   - The intake picks up balls automatically.
   - **F**: score while inside a goal zone. Jumping out of the robot ends the drive.

   Mobile and gamepad get on-screen buttons.
6. **Season** (🔄). This is the rebirth. It resets cash, workshop and robots, and keeps trophies. You get a permanent cash multiplier and unlock season-only parts.
7. **Shop** (🛒). Game passes.

## Updating from an older version
Paste the new `Installer.lua` into the Command Bar again. It replaces every script, and removes the old `ServerScriptService.RobotBuilder` (it now lives in ReplicatedStorage). If you installed by hand, move `RobotBuilder` into ReplicatedStorage and replace the other scripts.

## Customizing

Every price, stat, reward and robot part is in **`Config`** (ReplicatedStorage):

| What | Where in Config |
|---|---|
| Tycoon buttons, prices and machine output | `Config.Items` |
| Robot parts and stats | `Config.Modules` |
| Tournaments | `Config.Competitions` |
| Match length and rewards | `Config.Match`, `Config.Practice` |
| Rebirth cost and multiplier | `Config.Season` |
| **Game passes** | `Config.GamePasses`: create the passes on the Creator Dashboard and put their IDs here (`Id = 0` means disabled) |

If you edit the files in `src/`, run `python3 tools/build_installer.py` to rebuild `Installer.lua`.

## Project layout
```

  ReplicatedStorage/Config.lua            shared settings + stat math
  ReplicatedStorage/RobotBuilder.lua      builds 3D robots (world + UI previews)
  ServerScriptService/DataManager.lua     saving, leaderstats, cash, remotes
  ServerScriptService/WorldBuilder.lua    generates hub, fields, workshops, items
  ServerScriptService/TycoonServer.server.lua   tycoon, lab, garage, competitions, seasons
  ServerScriptService/ArenaServer.server.lua    practice + ranked driving
  StarterPlayerScripts/MainUI.client.lua        all UI (auto-scales, 3D previews, animations)
  StarterPlayerScripts/DriveClient.client.lua   robot driving controls
Installer.lua         generated one-paste installer
```
